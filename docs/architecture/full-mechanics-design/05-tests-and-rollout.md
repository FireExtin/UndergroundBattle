## 2. 可执行矩阵的使用方式

[test-matrix.json](test-matrix.json) 将已存在的测试入口与下面 T01–T29 场景关联。运行：

~~~bash
# 从仓库根目录执行；只读源文件，输出到临时目录
python3 docs/architecture/full-mechanics-design/evidence/verify_design.py
python3 docs/architecture/full-mechanics-design/evidence/run_checks.py --list
python3 docs/architecture/full-mechanics-design/evidence/run_checks.py --run native
python3 docs/architecture/full-mechanics-design/evidence/run_checks.py --run storage
python3 docs/architecture/full-mechanics-design/evidence/run_checks.py --run wasm
python3 docs/architecture/full-mechanics-design/evidence/run_checks.py --run receipt-probe
python3 docs/architecture/full-mechanics-design/evidence/run_checks.py --run coverage
~~~

runner 以审阅 SHA 的临时 git archive 执行，生成物不写工作树；需自行已有 Rust 1.90、wasm32 target、wasm-bindgen 0.2.104、Node、Python。它不会下载工具、运行部署或把失败改成成功。coverage 预期会重现已知失败，receipt-probe 的成功代表“观察到缺口”，不是契约正确。

**未来场景是可直接翻译为夹具的输入/动作/断言规格，不是已存在的实现测试。** 矩阵逐项标注哪些有现有测试覆盖，以及哪些必须新增。不存在的新机制不能伪造一个绿灯测试。实现时将对应 fixture 放入 Rust 测试/跨目标 fixtures，再保留矩阵的场景 ID。

统一执行协议：给出固定 seed 和精确对象/座位/区域/计数器；从 `Game::apply` 或正式 room API 输入，不直接调内部 resolve 来跳过声明；对非法动作断言完整状态相同。凡有选择/响应的场景，在每个可暂停点序列化、重新读取再续接，与不中断轨迹比较。对同时选择打乱提交顺序，比较最终状态和公开轨迹（允许每人收据/提交事件的合法顺序不同），不能要求整个命令 journal 字节序相同。

## 4. 最小新增测试骨架

以下展示如何把场景落实为代码，函数名为建议接口，**不是当前可编译 API**。保留断言的是游戏结果和恢复行为，不是逐行镜像实现。

~~~rust
// T12: 同时选择不因提交顺序泄露信息或影响最终洗牌结果
let initial = hong_kong_fixture(seed, four_distinct_searchable_decks());
let a = run_with_restart(initial.clone(), [0, 1, 2, 3], restart_after(2));
let b = run_with_restart(initial,         [3, 1, 0, 2], restart_after(1));
assert_eq!(a.final_game_state(), b.final_game_state());
assert_eq!(a.reveal_batches(), b.reveal_batches());
assert!(a.before_barrier_views().all(|v| v.no_other_player_selection()));
assert_eq!(a.shuffle_count_by_player(), [1, 1, 1, 1]);

// T27: 竞争依 service CAS，而不是浏览器计时器先响
let room = response_window_fixture(opened_at_ms(1000), window_id("w7"));
let begin = begin_intent("w7", seat(0), command_id("b1"), server_now(5999));
let timeout = timeout_pass("w7", seat(0), server_now(6000));
let committed = race_via_real_store(room, begin, timeout);
assert_eq!(committed.winners(), 1);
assert_eq!(committed.total_resources_paid(), 0);
assert!(committed.old_window_commands_cannot_mutate_next());
~~~
