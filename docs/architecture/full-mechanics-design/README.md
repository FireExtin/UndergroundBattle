## 先交给实施线程的结论

1. **不要撤回 JC042 的 Immediate 修复。** 霸权 PDF 第 15 页明确把减费行动列为不可响应；费用牺牲引出的死亡触发仍应独立处理。现有 `ResponsePolicy` 比“只看 Fast”正确，应扩大使用。
2. **先收口生命周期与事件，再开放复杂牌。** JC028 的“牺牲自己后作为鲜血结附”需要付款后的实体转移凭据；只有来源快照或原目标 ID 都不够。封印、结附、潜伏、闪烁、控制变化和转变不能共用一个含糊的 `move`。
3. **不要把现有 `icons()` 提升为通用有效属性查询。** 对抗的临时图标、效果计数、恐怖有不同的原文口径；还必须支持多类型、多领域、非玩家操控者和有效能力。
4. **不要把所有触发都变成自动监听器。** 同时触发存在玩家排序和可选/强制之分；JC077 有“将受伤害”触发；香港有同时选择与同时公开。需要持久化阶段和选择屏障，不能用普通 `ForEachPlayer` 冒充。
5. **固定目录存在可复现漂移。** 此代码实际为 **26 张玩家定义 + 4 张世界定义**，五套自定义 50 张预组；起始目录还写 25 + 4。目录校验失败不应通过放宽门槛消除。685 是研究记录数；起始 B01 只有 9 张整卡规格，后续固定增量为 68，都不等于可玩接受数量。
6. **native/Worker 的规则共用不等于服务契约一致。** native 同座位复用 `commandId` 时不比较新请求意图；Worker 比较。应补齐原有收据契约，不增添新的签名系统。
7. **有明确规则缺口的卡继续隔离。** “转生”原图没有目录转写加上的“改为”；灵体/撤回的手册分类与霸权分类不同；非资产存在版次冲突；永恒、危机模式、部分 2V2 触发排序等证据不足。不能照搬其他 TCG 裁决。
