## 源码实现

- 无目标标准事务，支付印刷费用后进入正常响应堆栈；牺牲是结算效果，不是额外费用。没有宿主仍可合法打出，不添加卡面未印的每回合限次。
- 在结算时统一捕获所有由行动玩家当前操控的明置宿主角色、死亡前快照和原物理地区身份；不取暗藏者、非宿主、资产、队友或敌方控制角色。
- 复用同批死亡派发与宿主离场清理。原单位返回值的批量移除入口保持不变，新增内部凭据入口；实际移除角色的原实例ID、实际新墓地实例ID和拥有者由底层移除函数直接返回，不按牌名、位置或最后一张墓地牌推断。
- 同一固定操作内完成整批牺牲，再用精确墓地实例返回原物理地区。牌已不在该墓地、地区消失/空缺/被同索引新地区替代时不另找同名牌或地区。复用已有墓地进场入口，重置身份、标志、横置、损伤、护盾及控制权，派发Enter而非Reveal。
- 死亡与进场声明在整个操作完成后由既有队列处理，没有可保存的中间待选续体。固定定义、支付、来源、步骤、堆栈外壳及直接/重复效果或伪造待选均有恢复守卫；同时接入Game和Room加载器。
- 只增加JZ35：候选池138张；原137张、牌组、世界和其他元数据保持不变。版本为 `rust-v0.2.72-jz35-host-return-candidate` / `limited-v2.65-jz35-host-return-candidate`。原图副本、扫描清单与客户端URL已登记，旧来源测试保留历史基线哈希并排除新增卡。
