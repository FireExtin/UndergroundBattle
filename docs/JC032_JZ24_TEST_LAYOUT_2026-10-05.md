## JZ24 双敌交错固定布局

actor=2（队友3，敌A=0/B=1），JZ24位于region2并通过真实conceal→reveal→可选trigger→响应结算。A/B各手牌3。region2：A操控host JC016，**owner=B**；挂BQ022（owner=B/controller=B）。B另操控一个正面JC029。各席另有region1角色与隐匿角色作排除对照。只初始布局建立借控与附属，不经公网注入。

| 检查点 | 操作 | 必须满足 |
| --- | --- | --- |
| T0 可选声明 | 首局跳过trigger；次局发动 | 跳过不牺牲；发动不是固定必选声明。Reveal触发，普通deploy无触发 |
| T1 响应后初始取样 | 回应可将A手牌4→3、B3→4的对照 | 在**首次效果执行**取样，非Reveal或声明时；对照A入/B出 |
| T2 A pending | 主局A/B均3时结算 | 顺序A0再B1；A候选只有其控制、原region2、正面角色，不按owner；min=max1 |
| T3 A完成→B pending | A选带BQ022的host | host进owner=B墓地；BQ022立即回B手牌、新实例，B手牌4；**仍产生B的强制选择**；剩余cohort不重新按手牌过滤 |
| T3恢复 | 保存上点完整状态，恢复后与未恢复分支均选B角色 | 相同完整结果；不再牺牲A、不再次返刀、不取消B；读视图不推进续体 |
| T4 完成 | B选择正面JC029 | A/B各牺牲一次，角色去各owner墓地；下一Death触发按现有effects队列处理，不能插入并改变B取样 |

对照：B首次取样已4，稍后降低到3也不加入；A/B开始0/1/2/3均合格，4不合格；队友即使手牌0不加入。各actor0..3顺序依现有FromActor循环过滤敌席（0/1→2,3；2/3→0,1），不是官方顺序主张。

额外组：受影响席无正面本地角色则继续下一席；来源Reveal后移区/离场仍在原region2结算；原地区替换的失效/过期策略同上待父审；用真实有Death触发的XQ12为牺牲对象，验证下一敌选择先于待处理Death声明，未重复触发。只冻结席，不冻结角色候选：前席处理后下一席候选依当时本地controller生成。

非法选择分别测空选、两选、同ID重复、队友/敌另一席角色、owner相同controller错误、其他地区、隐匿、附属、旧实例、旧choice、非pending席与重复command；全部严格无变化拒绝。四席只在当前被要求席有pending/options，其他席不得得到私有手牌身份。
