## 执行与恢复约束

- 标准行动按印刷费用和忠诚打出，选择任一真实在场地区；复用已有地区结附、响应堆栈及物理地区实例守卫，不增加角色宿主或普通派遣距离限制。
- 秘密派遣的即时费用为 `1 + 该物理地区上未横置的有效 XQ25 数量`，对所有玩家生效，与探头拥有者、操控者和队伍无关。多张探头叠加；横置、消灭或离场立即停止贡献。
- 费用按实际行动提交时的状态计算，沿用原子支付。支付不足时手牌、资产、每回合秘密派遣额度、随机状态及版本均保持不变。正面派遣与付费翻开仍使用原有印刷费用；公开牌、派遣距离及每回合限制仍适用。
- 加费时合法动作追加 `（费用：支付N）`，现有 UI 根据费用与目标地区区分动作组；无加费时保留原标签。没有新增探头自行横置或触发能力。
- 声明冻结目标地区实例；响应期间原地区换位/离场会使结附取消且不退费，不会把探头结附到槽位中的新地区。成功结附后的已通过守卫可正常执行，持久化响应堆栈则只接受未检查守卫。
- Game 与 Room 恢复共同拒绝非法宿主、暗面探头、越界操控者、重复实例、改写的结附程序/堆栈外壳、直接效果队列及伪造触发/续体待选。
- 地区被赢走时探头参与既有拥有者回底批次；宿主单独离场按既有结附规则进入拥有者墓地。结附于地区不会触发仅观察本方角色宿主的 BQ030。
