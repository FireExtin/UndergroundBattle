# PDF 原稿验收依据

本轮默认规则是仓库内《霸权说明书》扫描原稿，不是整理版规则、OCR 或旧 Go 的行为。印刷页码比 PDF 物理页码小 1；PDF SHA-256 与逐卡原图证据见 `rust-game/data/source-verification.json`。OCR 只定位页码，以下结论已经实际查看扫描页。

| 范围 | 原稿印刷页 | 必须保持的行为 |
| --- | --- | --- |
| 初始与再调度 | 6 | 手牌 6；原牌暂放，先抓等量，再把原牌洗回；只能再调度一次。 |
| 图标与行动 | 6、8 | 临时白底图标只在操控者团队持先手时有效；横置角色不参与对抗；资产与秘密派遣各人每回合各一次。 |
| 调查 | 9 | 奖励 X 是双方调查图标差值；检视顶 X 张，自己决定顶/底及顺序，然后抓 1 张；不直接加势力。 |
| 战斗 | 9、17 | 奖励是图标差值，加已参与获胜角色的杀伤；获胜玩家选择分配，同一批伤害同时发生；护卫要求先满足。 |
| 势力及赢区 | 9 | 抵消敌方标志后放差值；赢区前有快速窗口；地区上的牌归各拥有者选择顺序置牌库底；撤回例外回手。 |
| 翻面 | 11 | 暗藏者不是角色，不承受角色伤害；現身付完整费用并满足忠诚，进入堆叠；現身/潜伏保留横置状态，旧目标引用失效。 |
| 标准与快速能力 | 10、14、16 | 目标与模式先确定，费用随后支付；來源离场不撤销已发动能力；事务先执行效果再入墓；每个堆叠对象结算后重新给行动权。 |
| 机动 | 18、21 | 只有重置角色能发动；属于可响应的触发能力；先手方先移动再后手；双人可跨地区，2V2 只能相邻。 |
| 独有、屏障、护盾 | 3、18 | 同一操控者同名独有角色出现第二张时必须选择牺牲一张；屏障禁止敌方指定；护盾强制减一并终止敌方来源效果。 |
| 2V2 | 21 | 五地区、团队 10 分、队伍行动权、全队让过才交出；左/右席位正常派遣只到近侧三个地区；调查/伤害的执行者必须实际贡献相应图标；队友不看手牌和暗藏者。 |
| 牌库耗尽 | 3、21 | 必须抓牌而牌库无牌时，双人即时失败；2V2 该人退出，移除其牌但保留计分，其队友继续。只把最后一张牌抓走不立即失败。 |
| 构筑 | 13 | 至少 50 张，同名最多 3 张，印刷例外优先；秘社可选。 |

四套可选牌组是受限真实卡池的自组预组，不是《霸权》印刷页 13 的官方四套预组。每套 50 张，其中无知路人依其印刷例外可超过 3 张。每张开放卡牌的完整印刷能力都必须有实现；其余牌不进入可选卡池。基础版、扩展版和经典 2V2 的额外机制不因此自动获得支持。

本卡池的护卫只有护卫 1。若伤害少于多个护卫的护卫值之和，按“先分配给护卫”的要求，全部伤害先分给护卫；不能向其他角色分配。原页未单列该不足情形，这是明确记录的实现解释，避免让玩家进入无合法分配的选择。

待裁决的窄边界：若双方在同一个开始抓牌步骤都已空库，原页 P3/P8 没有明确多人的逐个抓牌顺序或同时败北结果。当前引擎按座位顺序逐个抓牌并立即处理失败；这不是已由原稿确认的同时空库规则。正常单人空库失败及 2V2 队友续局已有验证，不能据此宣称这一边界已解决。

自动测试与浏览器试玩的预期值应来自这些原页和卡牌原图。浏览器收到的合法动作可以用于选择点击目标，但不能作为规则正确性的独立证据。完整对局、隐私、幂等和恢复是不同验收维度，不能用单个编译或一张截图替代。
