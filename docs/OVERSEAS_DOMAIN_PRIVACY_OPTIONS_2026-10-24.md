# 海外域名隐私选项：只读核查

当前默认网址仍含账户命名空间，尚未满足用户“域名里不要有我的任何个人信息”的要求。本轮没有更改 URL、DNS、站点访问设置或部署，也没有购买或绑定域名。

按官方 Sites 技能及现有接口核查，`sites_get_site` 返回当前活动 v1 的默认网址；未返回已验证的不含账户标识的替代默认网址。`sites_list_custom_domains` 成功返回空列表。

|官方选项|已核能力与限制|
|---|---|
|修改 slug|`sites_change_site_slug` 仅提供 `project_id` 与 `slug`，说明为修改公开 URL 标签；没有账户命名空间参数，不能据此承诺删除整个主机名里的账户后缀。本轮未调用。|
|自定义非个人域名|`sites_add_custom_domain` 支持已发布站，返回子域 CNAME 或根域 A 目标及必需的验证记录。需要用户控制的域名、后续绑定操作、DNS 验证和有效 SSL 后才能路由。当前没有已配置域名，本轮未调用。|
|匿名默认域名|当前官方回执和可用接口没有提供已验证选项；不据此推断平台永久不支持，也不猜测其他主机地址。|

因此可供下一步选择的是使用用户已有且不含个人信息的域名；本轮仅报告该能力，尚缺具体域名及配置决策。现有接口也没有明确提供关闭生成默认网址的能力，不能承诺绑定后默认网址不可直接访问。
