每条的完整原图路径和哈希在规格内；规则页在 `faction-coverage.json.evidence`。本批补看规则手册 P2/P10/P11（PDF 4/12/13）及霸权 P3/P4（PDF 4/5），核准可选触发、所有在场牌的重置、牺牲控制者限制、抓牌事件与自我指代。

基础秘社也会横置，后续重置必须覆盖在场秘社。白底图标仅对抗参与时依先手启用；其他效果数图标时仍计白底图标。灵体数魔法领域图标，应有自己的统计接口，不能复用调查/战斗/势力的参与数或把领域当作五色之一。

印刷名字指代的是此来源实例，不能因另一张同名牌在场而把它当成效果对象。独有（金色名称）、领袖（每玩家一个领袖）和唯一（构筑一张）须保持三种独立规则。

## 仍需规则设计明确的点

JC077 的改伤触发可以响应，灵体又防止伤害；原文确认了改伤对象和条件，但统一伤害事件、防止/替代与触发入堆叠顺序仍需明确。规格状态为 `needsRuling`，不伪造完整伤害层已设计。

秘社“若你具有先手标志，则抓1”写在效果段。无先手时能否付费发动、响应中改变先手如何检查，须形成统一条件行动语义；不能为方便界面自行增加卡面没有的发动限制。本批积极路线可先用于规则设计，但这种疑点不应被隐藏。

本批确定性白色案例以1V1为准；2V2声望/灵体涉及本方、友方及团队计数，需结合霸权队伍原页另核。只有香港案例明确覆盖四人“每位玩家”。
