## 原始依据与修正

逐张实读仓库中五张原图，字节SHA与固定规格一致；文件路径和SHA保存在同名JSON。实读《霸权说明书》PDF物理20/22页（印刷19/21），以及《隐秘世界规则手册》PDF物理10/11页（印刷8/9）。前者确认饮血的操控者、墓地/本人秘社封印来源、隐秘加值和2V2本方边界；后者确认弃牌由被要求弃牌者选择、袭击属于现身触发且可叠加、能力发动后来源离场不取消堆叠能力。

本次更正原固定规格中的五张记录：BQ031/BQ032非资产前的日形符号是条件；BQ027/BQ036/BQ038紫色加值不是地区势力。保留金名独有、副名、费用、忠诚、图标、血魔法及其他原文。两个旧来源门禁保留原先四项修正断言，并额外排除本包五项后，与精确基线的其他来源记录哈希比较。新增第三项验证235条旧目录、五张仍非完整先行牌、原图和规则PDF字节。原四项记录及本批总数不改成新的完成数。

## 实现与边界

饮血来源继续使用 `batch3_blood` 的 `blood_drinker` / `blood_options`。仅抽出 `attach_selected_blood` 这个区域迁移原语：检验当前操控者、实际从其墓地或本人秘社封印取出、刷新实体、保留拥有者、按当前操控者结附。原第三批续体仍走同一校验。饮血2先确认全部选择，再同批置入；随后调用已有进场观察，不补造手牌或免费印刷出牌。现有鲜血附属宿主限制仍生效。

千军按真实成功结附捕获原角色类别、操控者和附属事件；附属可以由他人操控，角色必须是本人，跨地区有效。只在接受触发、入栈时消费原 `turn_ability_usage`，拒绝/零触发不消费，响应后来源或宿主离场不抹除已经发动的事件。目标敌方玩家自行私有弃牌，空手不制造待选。用现有排序引用队列与裁定官/欢宴共存；真实转移结附也注册该队列。不同结附事件使用不同事件ID；两张鲜血不会绕过每回合一次。

掠食时刻捕获成功入栈的袭击，而不把仅现身或放弃袭击当作袭击。依据是原手册将袭击定义为现身触发能力，并将“发动”定义为该能力入栈。印刷、JC038合并授予及XG11现有专属袭击程序使用各自原校验，不另造袭击结算。加总后的袭击是一次事件，不按伤害点数触发。观察含原袭击帧的有限历史收据，后续仍按原角色UID饮血；来源离场不重绑定。当前复用的饮血函数及两种鲜血的合法宿主都要求吸血鬼，未扩展非吸血鬼的饮血效果；原手册称饮血为吸血鬼专属，但本牌写“角色”，此边界留给父端结合原文复审，不将非吸血鬼饮血计作已覆盖规则。隐秘对抗触发尚未声明完成。

搜寻选项和完整顶六张预览只给原行动者，其他座位无待选内容。选出的牌按名称公开展示并刷新进入手牌；未选牌连同其余牌库走原确定性洗牌。允许零张、短牌库、空牌库和全部匹配；第七张、重复ID、无关载荷不能通过。来源在响应中离场后仍完成原玩家搜寻。

没有改费用/克隆提交顺序，没有引入第二内核、旧存档迁移或新外部服务。共享袭击入口在非袭击帧快速返回；未测吞吐量，不声称性能提升或性能基线复验。
