## 四条帷幕秘社

MSWM01 曼纽家族，Society12/17，起手6：蓝/黄/中立或其他色吸血鬼/阴魂角色；隐秘展示阴魂获+1。4＋横置秘社后，整局所有**拥有**的吸血鬼/法师角色牌额外阴魂，范围不是当前操控的场上角色。抓牌行动付横置秘社及一名本方阴魂；没有货币费用，条件是秘社无暴露，不是必须有隐秘。跨区整局类型层仍需设计。

MSWM02 公众安全委员会，SocietyP3/7，起手6：灰/黄/中立或其他色特工/媒体/互联网牌。横置秘社移除目标秘社所选类的全部暴露或隐秘，每局发动一次；正文明确许可秘社目标。另一行动2＋横置＋弃媒体/互联网牌为费用，随后隐秘对抗加值读被弃牌**印刷费用**。

MSWM03 冷山帮，Society16/17，起手5：非黑且非中立合计≤12。起始手牌前检索、展示黑市附属进手，再洗牌，然后再抓起手5。2＋横置秘社＋弃一牌＋横置本方罪犯都是费用；效果先抓1，若费用中弃的是罪犯牌，再将费用中实际横置的同一角色潜伏。不能付款后重新指定另一名。

MSWM04 梦魇主母，SocietyS2/3，右侧棕色牌叠起手2：仅紫，不能自动加中立；只忽略紫忠诚，其他颜色/领域仍核。横置行动加复苏；0行动按复苏数比较印刷费，免所选牌货币费但保留未豁免忠诚，每回合发动一次；第三行动横置并移复苏1为费用，检索贝兰丹娜后展示、进手、洗牌。底部另有三角/圆环图形内8，原图数值可读，但已核说明页未找到其字段含义；不能猜作手牌上限、分数或起手。本条新增 `additionalPrintedSymbols` 未清字段并保持blocked。免费打出/现身的嵌套声明与响应流程也待规则设计。

帷幕说明图明确提及七张勘误牌的印刷编号额外有R，包括隐士。这为B04实读的R15/17提供产品旁证；仅补版本说明，不跨版替换原图或猜改其他字段。
