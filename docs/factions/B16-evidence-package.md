读心术和获取装备印有独立隐秘地区势力栏，不是普通调查/战斗/势力图标。藏于深层意识有隐秘标志时改检索三张，心灵拓扑学按隐秘标志降费。召现雷霆先对横置角色造成4点伤害再横置其余，不伤害第二批刚横置者。“愿景”唯一/非资产/传闻、不能被响应、整牌库封印以及本局不能抓牌，需明确和抽空失败规则的先后。
