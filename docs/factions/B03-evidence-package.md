# B03：现有29定义的剩余原图与友方/护卫边界

本批完成19条原图的全部游戏字段：JC125、LC21、LC22、LC24、XQ49、JC118、JC002、XQ03、JC014、JZ08、JC059、XQ12、DQJC107、DQJC112、DQJC113、DQJC114、JC042、JC091、JZ54。输入是每条同ID完整JPG及原始说明书渲染页；输出见 [card-specifications.json](card-specifications.json)、证据清单和685条研究索引。没有用归档JSON文字完成规格。

截至B03，累计47条完成锁定原图的全部游戏字段，3条有未清字段而blocked；109条至少看过原图，其中62条仍部分核验；563条有原图待核，13条缺同ID独立原图。基线现有25玩家牌与4世界定义全部具备来源规格；其引擎等价与UI试玩仍未通过，本批没有把29条升级成implemented。

## 必须交给主实施的修正

JC059 安全保卫部门，原图059/135：3费用，**没有忠诚图标**，临时战斗2、永久势力1、防御2，公开；持续正文为“位于本地区的所有其他**友方**角色获得+1防御”。不含自身，不含暗藏者，也不是只含同一操控者。此前审计概述写本方，需要修正为友方。霸权队伍规则区分本方与同队友方；基线 `engine.rs::defense` 用 `other.controller == c.controller`，`rules.rs` 登记 `OtherControlledCharactersDefense(1)`，因此队友角色在2V2中的加防御覆盖不足。保持 `continuous=partial` 并追加这条具体缺口；不因1V1恰好等价就宣称完整实现。

LC21/LC22 的护卫1按霸权说明书印刷P17 / PDF18定义为战斗**伤害分配优先**：先至少给该角色分配1伤害，再给其他角色。它不是减免伤害，也不保护法术或地区造成的伤害。基线已有护卫分配检查；本批只补原图规格及数据防误改约束，没有执行Rust或游戏验收。
