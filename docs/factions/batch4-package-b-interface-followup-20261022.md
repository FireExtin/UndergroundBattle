## BQ038原文复核

重新实读五张B牌原图，并增读XQ14/BQ040鲜血原图、规则手册物理5/6页（印刷3/4）。BQ038第二条明确为场上“触发”，进行隐秘对抗时本人的展示牌获得+X；X是合格本人角色数量，不是附属张数，也不是该牌自身展示加值。BQ027的紫色整栏则是自身展示+2及本次对抗后的目标饮血。BQ036的行动加2同样只给本次本人展示牌。

两种鲜血原图都限定吸血鬼宿主。手册“附属和结附”规定附属持续保持其操控者，不因宿主由他人操控而变化；宿主不再符合要求时附属消灭。因此不能让鲜血稳定保留于非吸血鬼上。仍未读到明确裁定来区别“非吸血鬼饮血直接无效”和“先置入、随即因非法宿主消灭，并产生相关进场观察”；保持上轮旧饮血函数边界，不声称已解决此差异。
