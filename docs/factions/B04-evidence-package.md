## 可复用的基础模板

MSJC02–07各原图均要求牌组至少25张自己的颜色，起手6；两个标准行动分别为3并横置秘社、持先手时抓1，以及4并横置秘社、检索本色金色名称独有牌、展示、进手、再洗牌且每局发动一次。每条都单独读图，代码仅复用已核准的共同数据形状。秘社不计入25张/50张，检索入手不是抓牌，终止不返还发动次数，不能遗漏横置费用。缺先手能否发动及条件变化检查点仍登记规则疑点，不为方便UI增加原文没有的发动门槛。

## 设计疑点与验证

貘组明确选择封印在秘社上的角色牌，而封印通用规则通常清空卡面信息，需要保留卡面授权的印刷类别选择例外和私密投影。第一行动没有可封印星辰手牌时如何处理后续抓牌须继续核通用不完整效果规则，不能把效果选择改成费用。颂亡者墓地目标与七封费用可能重叠，能否如此声明仍待核；确定的是付款后已离开墓地的牌不能按旧墓地目标复活。原图字段完成与规则设计定案独立计数。

Python独立验证新增费用/效果位置、三名不同角色的横置费用、合计12张限制、双目标移动、首回合时机/七封费用与普通墓地打出区别，以及底抓不颠倒所有顶牌操作的防误改约束。所有卡级场景仍notRun，未执行Rust测试、未开房间、未做dot试玩或部署。后续实现必须由主线按共享机制分批，经过API、实际UI和2–4名独立dot策略试玩后才决定开放。
