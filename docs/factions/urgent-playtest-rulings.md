# 实玩定点交付：世界重复、0费路人及无中立候选预组

已重看《隐秘世界玩家指南》原PDF印刷P4/PDF6、P6/PDF8，《规则手册》P2/PDF4，霸权说明书P6/PDF7及10张地区/无知路人原图。准确页码和原文件SHA在faction-coverage.json的guide-base-world、guide-base-world-setup、manual-normal-play中。结构数据见urgent-playtest-rulings.json；这里的源码对照始终固定286ad83ef5a54bc0caed26199ca4cfea269314bd。

基础世界牌库是基础包全部十张地区，共用一套：沉没的废墟、佛罗伦萨、京都、伦敦、莫斯科、纽约、切尔诺贝利、上海、死者之城、香港，各一张。档案原图页脚为W01/10到W10/10，基础指南旧编号W107到W116，不能把印刷编号与档案ID当同一字段。各图路径/SHA和字段已有完整规格。复看时纠正此前转写：切尔诺贝利副名称是“水泥石棺”。

当前有限catalog的world实际只含DQJC107×3、DQJC112×3、DQJC113×2、DQJC114×2。engine.start按count逐个make_card，产生不同实体ID，因此同桌两张切尔诺贝利来自明确复制配置，不是显示名称碰撞。总计十张实体不等于十个官方基础地区定义。建议主线程补足六个已核地区定义及赢区效果，检验持久化/合法动作和新局后使用各一张；本研究线程不修改现有卡池或房间。对于任意跨扩展自选世界牌库是否普遍禁止同名地区，现有原说明未找到明确总规则，保留uncertain；序曲明确的同名唯一仅针对遭遇角色，不能扩大套用。

JC125原图确实印费用0、无忠诚/领域、无调查/战斗/势力图标、防御1。正常正面打出是己方行动步骤的标准行动：手中此牌、可进入的地区、合法窗口，无增费或额外费用时支付0，无须先建资产；入堆叠等待响应。0费不免时机和地区限制，不变成快速行动；卡牌持续效果可能改变实际费用。卡面同名数量不限仅是构筑例外，不能作为用17张路人代替派系特色的依据。已有源文件与新增未运行验收场景可供主线程核UI/引擎。

用户明确要求后续候选预组不使用中立充数。deck-proposals.json给四组50张设计候选：黄绿横置与猎手、蓝红血族与献祭、灰黑暗藏者与墓地、白紫声望与封印。覆盖全部八色，分别23+27张，每组17个已完整核验的不同名称，普通同名上限不超过3，零中立牌，不含字段阻塞记录。它们是研究提案，不是原作官方预组或当前可玩牌表，选择始终false，游戏与UI验收未运行。每项附完整来源规格引用和共享机制补全优先级；主线程需要逐张完成完整能力实现与试玩后再解锁。

本次同时统一来源数据的中立颜色键为“中立”，防止研究显示出现“中”别名；不改变棕色徽记或彩色忠诚观察。新增独立数据验证防止中立替换、来源完成即解锁、同名定义重复混入官方基础世界。未改引擎/生产cards.json/React/在线房间，未发布。
