# TK008生成角色的规则缺口（未作裁定）

## 2026-10-29 原件复核更正（替代下列旧费用待决结论）

此前只核对扫描手册后部及文本提取，遗漏了《霸权说明书》印刷第5页（PDF第6页）的“指示物角色牌”。原件明确：“指示物角色不能被作为资产。其印刷费用为0，也没有忠诚需求。”PDF SHA256为 `a1e5bca72b8dbb374357feace28b7fbfd31136349ee23455d60f5f62e0a6b886`。渲染页与来源清单位于本轮本地证据 `cq11-validation/hegemony-page6-verified.png`、`official-token-cost-source.json`；原件仍为仓库跟踪的 `resource/ymsj-fun.github.io/public/docs/霸权说明书.pdf`。

这项明文解决TK008的规则数值费用与忠诚问题，不等于所有没有印刷费用的实体卡均为0，也不使指示物成为可构筑牌或手牌打出对象。《隐秘世界规则手册》印刷第1页允许在快速行动时机支付角色费用、满足忠诚后将暗藏者翻正。结合本项目已决的生成物翻暗保留，TK008应能正常零费现身；TK010不能普通现身的既有项目特例继续保留。

生成物离场消失、翻暗保留、封印留场仍按已委托项目裁定；其中翻暗保留不是原版手册规则。下面旧调查记录保留为历史证据，不再作为CQ11/TK008费用阻塞。当前更正本身不代表卡牌已经完整实现、独审或开放准入。

原第三批候选CQ11「暴乱煽动者」现移至待裁定队列，由同优先级蓝色CQ07「菲碧·π」替补本批；CQ11与TK008仍未实现或准入，以下缺口及规则均未改动。其进场文字是在本地区生成一个邪教徒角色指示物，对应TK008「邪教徒」。这不是常规中立卡扩展。TK008原图无印刷费用，不得转写为0费、可从手牌打出或可构筑卡。其正面为红色人类/邪教徒，永久势力1、防御1；行动牺牲三个不同本方邪教徒角色以毁灭目标地区，来源不必是三个牺牲对象之一。

## 需要一次确认的状态转换

以下都是候选解释，尚未选择任何一个；不能套用其他游戏的指示物规则。

| 转换 | 缺少的明确依据及候选解释 | 受影响机制 |
| --- | --- | --- |
| 致死、消灭、牺牲 | 是否先正常死亡后消失、进入墓地后保留，或在死亡事件前移除？ | WM035宿主和现有角色死亡观察、牺牲费用、墓地复活 |
| 回手 | 消失，还是成为留在手中但不能正常打出的生成角色？ | 回收、弃牌、手牌数量、再次暗藏 |
| 牌库顶/底（含赢得地区后的回底） | 消失，还是成为正常牌库对象？若保留，之后抓牌和磨牌如何处理？ | 回底、洗牌、抓牌、磨牌 |
| 封印 | 消失，还是保留为空白封印牌；载体离场时是否正常回手？ | 封印与返还、场内外/死亡的区分 |
| 翻暗/潜伏 | 允许并保留但不能普通付费现身、禁止翻暗，还是转为某种离场处理？ | 暗藏者身份、检视、现身、隐藏信息 |
| 无印刷费用的数值比较 | 仅在比较时按0，还是不具备可比较费用？ | BQ089印刷费用上限、JZ26最低印刷费用选择 |

普通地区间移动不等于离场，不据此假定指示物消失。若生成实例保留于非场内区域，还需明确文字中的「角色」和「角色牌」如何适用。裁定可统一覆盖生成角色，也可仅明确TK008；在获得依据前不写入引擎默认解释。
