# B20：帷幕之后红灰白黑紫36张

WM038–047、049–070及072–075共36条完整原图、图标和必要正文放大区人工核验，累计501条完整来源（500张牌面、1标志参考），178条可读来源待核；5条原字段模糊和TK011缺图仍隔离。

公开、声望、机动等关键词旁的太阳图形与“秘社上暴露标志”按文字位置分辨。精神分析师移除本方暴露作费用后给永久调查至回合结束，心理审察委员进场移除全部秘社暴露并按实际移除数遏制；快速医治反而新增本方暴露。阿尔法先生全体本方公开获得声望、全体敌方失去声望。

计划：新秩序翻全体角色成暗藏者及同玩家同地区多暗藏者洗混；天眼按带锁定角色/暗藏者数量抓牌；贝奥武夫只清领域角色。完整印刷限制不合并成同一个计划模板。灯塔看护人有印刷分数1和唯一，计分入区须独立实现。高文的额外两个战斗图标均为永久；条件神圣领域授予不是印刷默认领域。

黑市的三种弃牌行动和敌方发动条件清晰，但未印结附对象，列WM063AttachmentTarget设计疑点，不自行补对象。多情达莉娅为临时调查2、永久势力2；巨蟒纹身赋永久调查1/战斗2/势力1、防御2及领袖/声望/罪犯。黑色徽记额外三角形保留观察事实。

诡辩家反转本地区本回合调查胜负及奖励。尖鸣突变体未横置时只将隐秘能力框视空白；蠕动灾祸封印后将受体印刷文本框视空白并失去图标至回合结束。丝琪取走双方类别势力图标，保持永久/临时各自类别。第六感默认临时调查，宿主改永久调查，均经放大确认。

所有新规格仅原图研究，选择禁用，游戏及UI验收未运行。未改共享引擎、卡池、React；未部署。另以原图名称局部核对更正WM024阿剌穆特字形，不采用定位表作为最终名称依据。
