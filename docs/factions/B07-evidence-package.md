## 解决的疑点与关联修正

重看[规则手册](../../resource/ymsj-fun.github.io/public/docs/隐秘世界规则手册.pdf)印刷P11/PDF第13页，`manual-marker-inheritance`：角色上的标志也视作位于其所在地区；附属上的标志也视作位于其所结附的牌或区域。标志实际仍留在原对象，计数可包含下挂对象。

这解开JC048沙漏的放置/地区计数差别。准备强制触发先在自身放时间，再按**整个结附地区**的时间总数造成范围伤害并判断至少3时间牺牲；同地区祭司上的时间也在范围中。新增待执行场景：沙漏原有1、同地区祭司有1，准备给沙漏再加1，地区计3，对每个正面角色造成3伤，然后牺牲沙漏。没有把原文“该地区”改成“该牌”。此前needsRuling原因撤销；未冒充已完成引擎流程或游戏测试。

B06对触手的目录关联误写TK004，现修正为目录候选TK010；TK004是炼金巨像。13条缺图名单未变，不能将目录关联当作原图数值证据，BQ060生成触手的规则定义仍受缺图阻塞。
