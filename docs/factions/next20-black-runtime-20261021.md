## 与传闻批次的整合接口

灰组的最终入墓搬运流程调用 `Game::observe_black_deck_to_graveyard(deck_seat, actual_cards)`，其中 `actual_cards` 为替换处理完毕后的新墓地实例，传闻改为封印的牌不在该列表。每批仅调用一次；JZ50检索也经过同一收口。

本分支为独立测试在旧 `mill_cards` 和JZ50收口临时接入上述回调。整合时保留灰组可恢复的 `GraveyardTransfer` 搬运实现，并移除灰组临时同名空函数，避免重复通知。CQ26使用标准 `Op::Discard { count: Some(1), optional: true, redraw: true }`；传闻替换后按实际弃牌结果计抓牌，完成的CQ26帧可由传闻批次调用 `validate_black_next20_frame` 认证。
