# 让过到指定阶段（WIP，未发布）

输入：用户要求一键连续让过，并明确优先“让过到指定阶段”；选择“结束”即处理本回合剩余窗口，到回合结束停止，不跨回合持续。当前正式站 v57 不包含此功能。

输出：`continuousPass.ts` 依据 Rust `Window` 投影定义边界；`AutoPass` 复用原命令管线和单个去重计时器；`Table` 标记手动操作；`useGame` 仅为活动自动操作保留原有后台快速同步策略。

- 行动、对抗：到达该阶段时停止，目标阶段不再自动提交让过。
- 结束：包含 End 窗口及清理，直到 `turn` 改变或游戏结束；下一回合绝不自动让过。
- 只提交自己的合法 `pass` 或当前响应窗口的 `passResponse`。不会发动连锁、取消已编写响应、支付、选牌或代替队友/对手操作。
- 任意选择、暂停、断线、未确认行动、手动操作或牌桌/席位改变都会停止。刷新默认关闭。取消只阻止后续让过，已提交命令仍按原回执确认。
- 此模式不持久化；开启时关闭原“仅无可用行动时自动让过”偏好，防止取消后另一模式继续操作。原功能仍可单独开启。

依据：`rust-game/src/engine.rs` 的 `view` 阶段投影、`close_window`、`pass` 和 `NextTurn`；响应命令沿用 `api.actionForRoom` / `ResponseWindow` 现有协议。未更改 Rust、Worker、数据库或 WASM。
