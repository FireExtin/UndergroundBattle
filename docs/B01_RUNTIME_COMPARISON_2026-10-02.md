# B01 与当前执行卡池的只读对照

资料批次来自 `bada475`，已合入 `2df59bc`。本对照针对 `rust-v0.2.3 / limited-v2.2`，不修改研究线程所有的覆盖统计，也不将整卡资料核验当成运行验收。

9张完整锁版规格中，现卡池已有4张：JC003、JC016、JC049、LC23。逐项比较其名字、费用、子类型、永久/临时图标、防御（仅角色）、金色名称/独有，均与规格相符；忠诚颜色和数量亦相符。JC003/JC049心灵各1、JC016无领域、LC23血脉1；LC23的旧运行字符串仍用“鲜血”，这是显示/规范化别名，后续统一领域模型时须保留真实领域身份，不能与同名鲜血附属混为一物。

| 卡 | 当前声明与B01关键边界 | 对照范围 |
| --- | --- | --- |
| JC003 | `Assets(2)+ExhaustSource`为费用，目标`CharacterOrHidden/Any/Anywhere`，效果横置目标 | 声明没有擅加同地区限制；响应及结算仍依通用目标guard。没有执行B01新增的逐卡游戏场景 |
| JC016 | `NoEnemyCharacters`条件增永久势力1/临时调查1，`kill:1`和`retreat:true` | 声明的永久/临时槽位正确；敌方暗藏者是否算角色、跨控制权时机等须由相应游戏案例验收，不凭字段判断宣布完整通过 |
| JC049 | `SacrificeSelectedControlledCharacter`额外费用、`MoveBottomToHand(count:2)` | 使用本方正面角色费用原语；没有误作`Draw`事件。未新跑其独立策略用例 |
| LC23 | `Reveal`触发，空能力费用；`Exhaust(Source)`与`Exhaust(Target(0))`都在效果段，目标同地区正面角色 | 当前源码已符合“来源横置是效果”；无需重复修复。已横置来源、目标失效令整段取消、独有等B01场景仍标`notRun` |

另外5张完整规格没有在执行卡池开放：DQJC116、JC070、JC076、JC077、MSJC01。香港仍须同时提交检索、同时展示与入手、最后分别洗牌的可恢复多人中间态；不能用逐人普通抓牌替代。白色三张分别需要声望、灵体和改伤语义，MSJC01需要秘社在场/重置/每局一次/构筑条件；在机制依赖完成前保持不可选。

MSJC08/09的副名称尚模糊，整卡资料仍blocked。B01的50条运行场景保持`notRun`；未补图记录不解禁。这里只确认资料已经被实施者吸收及四张现存声明的对应关系，未扩大卡池或启动架构重写。
